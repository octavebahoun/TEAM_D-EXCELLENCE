# Mecano

Mecano est une plateforme de boutique pour une concession automobile, réalisée pour un client via Excellence Team. Seuls le type de projet et l'adresse du site sont notés.

| Champ | Info |
| --- | --- |
| Type | Projet client, réalisé via Excellence Team |
| Contexte | Boutique en ligne d'une concession automobile |
| Liens | [Site](https://webgarage.excellenceteam.site/) |
